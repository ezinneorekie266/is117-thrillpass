
# Thrill Pass — Research and Project Documentation

Welcome to the Thrill Pass research project.

## About the Project

Thrill Pass is a proposed platform for discovering, comparing, and booking recreational adventure experiences in New Jersey and nearby New York.

This documentation records the team's research, comparisons, assumptions, decisions, and proposed website features.
